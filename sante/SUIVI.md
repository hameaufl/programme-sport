# Suivi chronologique des sensations — modèle

> **Aucun compte rendu réel enregistré.** Dossier public à ce stade. Ne pas renseigner de données personnelles sans validation explicite du dépôt cible et de sa visibilité.

## Modèle d'entrée (à compléter à partir d'un retour réel)

### AAAA-MM-JJ — activité / séance

- **Prévu :** …
- **Réalisé :** …
- **Durée / distance :** …
- **Sensations :** …
- **Gêne / douleur éventuelle :** …
- **Évolution le lendemain :** …
- **Récupération :** …
- **Décision Coach :** maintien / baisse / hausse / report / repos / attente
- **Séances concernées :** …
- **Origine :** retour daté du propriétaire / document explicite

Distinguer les faits transmis, les décisions d'entraînement et les hypothèses. Un ressenti n'est pas un diagnostic. Une case « Fait » n'est pas un compte rendu.
